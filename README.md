# SIPUSPA : PUSTAKA360

Plugin landing page OPAC SLiMS untuk Inovasi SIPUSPA : PUSTAKA360 Perpustakaan Poltekkes Kemenkes Semarang.

## URL
`index.php?p=sipuspa-pustaka360`

## Instalasi
1. Ekstrak folder `sipuspa_pustaka360` ke folder `plugins/` pada root SLiMS.
2. Login ke area admin SLiMS.
3. Buka System > Plugins.
4. Aktifkan plugin **SIPUSPA - PUSTAKA360**.
5. Buka `index.php?p=sipuspa-pustaka360` pada OPAC.
